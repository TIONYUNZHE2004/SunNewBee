### Rules for these tasks (agreed decisions)

- **No user text in storage.** Verification requests and the recurring-questions log hold structured fields only.
- **Explanations are deterministic.** Journey failure explanations come from engine facts, not an LLM. An LLM rephrase can be added later behind the mock.
- **Licences:** only MIT/Apache-2.0/BSD for new direct dependencies. No Pillow.
- **Mock for tests.** Use `LLM_PROVIDER=mock`. Live OpenRouter calls cost money, so keep them to a few smoke turns.
- **Wording changes:**
  - if mock answers change, re-record the Elmina demo cache with the mock; the replay-diff test must pass;
  - run e2e too, because it asserts answer wording.
- **Before a PR**, run the 7-step checklist in `AGENTS.md`.
